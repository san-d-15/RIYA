System Capabilities

Core Modules

Tools for local catalog, billing, stock, expiry, and reporting workflows

Medicine Management

Centralized catalog tracking generics, therapeutic categories, dosage forms, manufacturer details, and pricing structures.

Inventory Control

Tracks browser-local medicine quantities, minimum reorder levels, and low-inventory warnings. Sales and purchases update these local records.

Expiry Tracking

Proactive warning radar identifying medicines approaching expiry within 30-90 days with safe quarantine isolation.

POS Billing

Counter checkout with tax calculation, customer lookup, one selected payment method, and printable invoices.

Reports & Analytics

Daily and monthly reports calculated from sales and purchase records stored in this browser.

Java & MySQL

A separate Java/JDBC and MySQL prototype is included, but it exposes no HTTP API and is not connected to this browser UI.
